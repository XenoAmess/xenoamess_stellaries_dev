# 合成女王美化 Mod 测试策略

## 当前验收边界

`0.1.0` 首版只交付**人物肖像**：10 个原版肖像键共用一张新静态 DDS。剧情插画、对话背景、旗帜和奖励图标仍用原版，不能计入本次通过项。静态校验与简体中文实机校验分别报告；未观察到的人物场景记为“未验收”。仅在全部适用检查通过后，才称 Mod 验收完成。实机仅启用本 Mod。

## 静态检查

| 编号 | 检查 | 通过标准 |
| --- | --- | --- |
| S1 | 基线与原版差异 | 游戏版本为 `Pegasus v4.4.6 (fdde)`；原版肖像定义哈希匹配文档；Mod 文件恰好定义原版的 10 个键，各键以新图 `texturefile` 和原问候声音替代动画实体、贴图列表、选择器和镜头参数 |
| S2 | 包隔离 | `mod/` 只包含 `descriptor.mod`、10 键肖像定义、新 DDS 和工坊缩略图；不含原版事件、远端 ID、证据、生成源图或其他 Mod 文件 |
| S3 | 生成链 | 用户参考图、EvoLink 原始 RGBA PNG、预览图和 DDS 的尺寸、模式、哈希可追溯；重新运行构建脚本生成相同输出；检查 Alpha extrema、四角、`A>0/16/127` 包围盒，以及黑/白/外交蓝灰三底 SourceOver；DDS 解码后的 RGBA 与预览一致，没有烘焙棋盘格或全画幅半透明幕布 |
| S4 | 引用完整性 | `synth_queen`、`cetana_empty` 与 `get_cetana_face` 可选的 8 个键均指向存在的同一 DDS；路径与大小写准确 |
| S5 | P 语言 | 按 `C:\workspace\open_kaishek` 说明运行 Stellaris 配置检查；肖像定义和描述符没有语法或适用语义诊断；工具缺陷按仓库规则先修复、验证、提交并推送 |
| S6 | 版本 | `VERSION`、`descriptor.mod` 和 changelog 的发布版本一致；支持版本与实际基线相符 |

## 简体中文实机矩阵

使用隔离用户数据目录，仅启用本 Mod 和《机械纪元》，游戏语言固定 `l_simp_chinese`。优先沿用仓库桌面验收工具；运行入口、游戏版本、DLC、Mod 清单、存档、截图和日志写入 `evidence/runtime/`。先做启动与资源检查，再观察人物场景。控制台直接调用危机事件只可用于探索；正式证据需记录正确事件目标及 scope。

前次直启曾出现黑色/透明窗口；仓库的 [Stellaris 实机经验](../../docs/stellaris-runtime-testing.md) 已记录此种显示模式故障可用物理扫描码 `Alt+Enter`（`0x38` + `0x1c`）恢复。重试时先等待 `time.log` 的启动完成标记，再发送该组合键并复截图；仍无法绘制才记录为显示阻塞。

人物场景的隔离夹具先从人类联合国新开局保存 2200.01.01 存档；后续单独运行通过游戏原生 `commands_at_date.txt` 在 2200.01.02 对玩家国家执行 `event crisis.8005`，建立原版危机国家、物种、领袖和事件目标；确认生成后，在 2200.01.04 对同一玩家国家执行 `event crisis.8039`，由其选项进入 `crisis.8040` 对话。日期命令及种子存档哈希必须冻结在运行 manifest。直接触发危机事件会跳过自然触发年份，故仅作为美术验收夹具；是否满足原版上下文须以 `error.log`、存档目标和实际对话交叉确认。若命令未执行或 scope 错误，不将所得画面计入通过。

R2 先完成 `crisis.8040` 全部对话，再查通讯、物种或领袖界面；若“塞塔娜”外交仍返回“没有回应”且无独立物种条目，只记录为未验收。R4 可在独立运行中用原版 `crisis.23005` 结局事件制作视觉夹具：该事件的 `immediate` 创建 `portrait="synth_queen"` 的女王物种，并把新领袖改为 `cetana_empty`，事件图片引用该领袖。夹具必须记录命令、存档哈希、结局窗口截图、日志和事件作用域；只判断 `cetana_empty` 的图片显示，不据此证明危机自然结局流程。

重启游戏以检查 R5 前，先把当前 `game.log`、`error.log`、进程记录和关键截图复制到带运行阶段名的证据目录；Stellaris 下次启动会覆盖同一用户目录的日志。重启后再次归档日志和进程记录，并核对被载入存档的哈希，避免把两次进程的证据混为一谈。

| 编号 | 场景 | 通过标准 |
| --- | --- |
| R1 | 游戏启动及 Mod 装载 | 识别当前版本和本 Mod；无新增肖像定义、DDS 格式或找不到图片错误 |
| R2 | `synth_queen` 基础肖像 | 女王势力物种或领袖界面显示新人物，头冠和光环没有严重裁切，人物以真实 Alpha 融入界面 |
| R3 | `get_cetana_face` 外交对话 | 至少一种玩家物种视角的对话显示新人物且无矩形背景、光幕和明显 Alpha 边缘；其余 7 种类别确认映射并尽量逐项截图；全部类别共用新外观是预期设计 |
| R4 | `cetana_empty` 后期切换 | 后期领袖肖像仍显示新人物，无原版回落、黑块或错误姿势 |
| R5 | 存档重载 | 保存、退出、重进后人物仍正确显示，日志无新错误 |

第二阶段新增图片后，再扩展 2 张事件图、对话背景、3 张旗帜以及启蒙 zoom 裁切的实机矩阵。当前这些图保留原版，不因肖像阶段未替换而判为失败。

## 报告方式

每个场景记录日期、游戏 build、DLC、语言、实际加载 Mod、触发前提、原始截图或录屏帧、日志摘要和结果。明确区分“静态校验通过”“简体中文实机通过”“未执行/阻塞”。本 Mod 没有新增本地化；英文及其他语言运行时不在范围内。
