# 合成女王美化独立 Mod 实施计划

## 目标、范围与完成条件

建立可独立安装的合成女王（Cetana）图片替换 Mod，工作目录为 `synthetic_queen_beautification/`，暂定展示名 `XenoAmess的合成女王美化`。本任务当前只完成资源调查和文档准备；美术成品、Mod 包、实机验收与发布属于后续实施。

第一阶段替换 [资源清单](asset-audit.md)中的 16 个图片文件：10 张人物肖像、2 张剧情图、1 张危机对话背景、3 张旗帜。若原版人物视觉仍出现在剧情奖励图标中，再按清单第二阶段 5 个专属图标扩展；其余 UI、银河地图与 3D 材质不作为人物美化的默认范围。

验收标准：仅启用本 Mod 时，合成女王主要对话、所有可达形象变体、常规与启蒙事件、旗帜均呈现新图；原版危机逻辑、数值、声音及其他事件保持原样；与灰风 Mod 并用无图片路径冲突；[测试策略](test-strategy.md)全部适用项有证据，P 语言验收通过后方可宣告 Mod 验收完成。

## 目录与版本身份

规划目录如下。`mod/`、版本文件及工具在实际实施时按文档先行规则创建；现在不放置不完整的可安装包，防止被误认作已完成 Mod。

```text
synthetic_queen_beautification/
├── docs/                 # 本计划、清单、测试策略及后续验收记录
├── VERSION               # 后续实施时的唯一 Mod 版本源
├── CHANGELOG.md
├── mod/                  # 独立的可安装/发布 content folder
│   ├── descriptor.mod
│   ├── thumbnail.png     # 发布前再制作
│   ├── gfx/...
│   └── flags/...
├── evidence/             # 静态与简体中文实机证据，不进入 mod/
└── workshop/             # 如需发布再写远端合同和 Change Note
```

首个开发候选版本计划为 `0.1.0-rc.1`，不是已经发行的版本。`VERSION` 与 `descriptor.mod` 的 `version` 保持一致；`supported_version` 由实测游戏版本决定，当前调查基线为 `4.4.*`。本 Mod 使用独立的名称、版本、缩略图和新 Workshop 物品；不使用灰风或其他项目的远端 ID。没有用户后续发布要求时，不创建 Workshop 物品。

## 实施顺序与设计

1. **冻结基线。** 在开始制作美术前重查游戏版本、16 个源文件、DDS 头、引用与 SHA-256；把变化回写资源清单。留存原版文件的路径/哈希清单，不把游戏版权素材复制进仓库。
2. **确定美术合同。** 为 10 种肖像明确哪些共享主形象、哪些体现物种视角与后期空白状态；逐个制作 1024×1024 透明贴图。事件图以 450×150 出图并检查启蒙分支两种固定 zoom 视口；对话背景按 828×358 设计；旗帜分别按 256×256、256×256、24×24 出图。候选图、来源、版本和审核结论记录于 docs；不要用未经审核的自动裁切直接填充全部变体。
3. **采用最小覆盖。** 优先在 `mod/` 中保持原版相对路径与文件名，只覆盖确认的 DDS 图片，不重定义原版 sprite、portrait 或危机事件。这样现有事件、肖像键和旧存档仍引用相同路径。先做最小样例验证 Stellaris 的实际覆盖优先级，再批量装配。只有实机证明纯资源覆盖不足时，才设计最小脚本补丁，并先更新本计划。
4. **验收并修订。** 按测试策略执行静态、`open_kaishek` 和简体中文实机检查。发现新引用、裁切问题或不兼容先回写清单，再调整素材或包。第二阶段图标逐项依据画面证据决定是否实施。
5. **发布准备。** 只有另行决定发布时，才制作缩略图、正式 changelog、Workshop 文案、独立远端合同与新物品 ID；预发布版不上传公开创意工坊。发行前重跑验收并核对远端回读。

## 边界与风险处理

- 先用原版同路径图片覆盖，避免把 `events/machine_age_crisis_events.txt` 及 `common/scripted_effects/02_machine_age_effects.txt` 的大量玩法逻辑整文件带进 Mod。
- 旗帜的 `map` 与 `small` 版本一并提供；不能只替换主 256×256 文件。
- 肖像的网格、动画、房间及对话 UI 与 DDS 贴图不是同一种资产；若更换人物姿势导致骨骼/蒙版不合适，应先记录实机证据，再决定是否调整设计。
- `gfx/event_pictures/synth_queen_enlightenment.dds` 有固定 zoom 裁切；人物主体和关键元素必须在指定范围内可读。
- 原版“合成女王”内容属于《机械纪元》；实施验收须记录 DLC 启用状态。其他语言不进行实机回归。
