# PR-05 奖励池验收收口（2026-09-30）

## 目标、范围与设计

按[总验收方案](shishan-code-origin-acceptance-plan.md)合并已经归档的机械特质、兼容特质、四种迭代及运行时样本，明确哪些是实际游戏存档证明、哪些是 4.5.1 原版与正式 Mod 的静态契约。不得把反复直接调用奖励效果的压力夹具称为反复自然完成项目，也不以有限抽样声称统计概率正确。此次只读审计和文档归纳，不改奖励发放实现。

新增 `tools/shishan_code/audit_pr05_reward_exhaustion.py`：从已归档的原生奖励池耗尽存档读取主物种实际特质和四项迭代计数，记录存档 SHA-256。与生成器规定的 20 个机械、19 个兼容候选逐项比对；缺席候选必须由已持有的初始冲突特质或同层互斥选择解释。机械池和兼容池中其余合法候选应各恰好存在一次；四种迭代特质各恰好存在一次且国家计数均为正。还要复核白名单脚本的等权与目标作用域、19 个兼容映射的原版数值，以及四种迭代的实际 `1→2` 层量化证据。工具输出结构化 JSON 并对任何不一致返回失败。

## 通过标准

机械候选先于兼容候选，二者耗尽后才产生可重复迭代；候选排除与随机项零权条件一致，同层每项基础权重均为 `1`；主物种实际存档不含重复候选或非法冲突候选，兼容映射数值与原版一一相同；四类迭代在实机已有各自的增益方向及可叠加数值证据。原生存档应证明奖励实际写入主物种。项目 `n` 与费用仍由 PR-01/02/04 的自然项目路径单独验收。若现有证据不能满足这些条件，保持 PR-05 为 PENDING 并补实机或修复；不可因本工具对静态脚本 PASS 就自动宣布全部通过。

## 执行结果与证据边界

新审计对[真实游戏存档](../assets/shishan-code-origin/evidence/shishan_reward_exhausted.sav)及四组 `1/2` 层存档返回 **8/8 PASS**，机器可读结果见[PR-05 审计 JSON](../assets/shishan-code-origin/evidence/pr05-reward-closure-audit-2026-09-30.json)。主物种 ID `855638017` 的 43 个特质没有重复；20 个机械候选中实际获得 17 个，其余 3 个分别被开局已有的 `trait_robot_bulky`、`trait_robot_high_maintenance`、`trait_robot_repurposed_hardware` 阻断。19 个兼容候选中实际获得 16 个，其余 3 个分别与已选的兼容自然物理学家或兼容非常强壮互斥。四种迭代特质均唯一存在，国家计数分别为岗位 `7`、能量 `5`、空间 `11`、认知 `4`。原生存档 SHA-256 为 `554504e65d4b14d70fd91be3cb66c434c7c232ea37c109e70b7e2ebe93f4fccf`。

[候选契约审计](shishan-code-origin-pr05-candidate-contract-2026-09-29.md)在当前脚本上再次通过：三层 `if/else_if/else` 互斥，前两层每项可用条件与抽签零权条件相同且权重为 `1`，发放目标限定 `owner_main_species`；[兼容映射审计](../tools/shishan_code/audit_compat_traits.py)对全部 19 个映射与 Stellaris 4.5.1 原版数值逐项相等。原生压力存档证明两层所有**实际合格**候选已经写入主物种且没有重复；[抽完第二层画面](../assets/shishan-code-origin/evidence/reward-pool-second-tier.jpg)和[进入迭代层画面](../assets/shishan-code-origin/evidence/reward-pool-iteration-tier.jpg)保留游戏显示。四类迭代各自的 1/2 层原生存档均为一个特质、计数分别为 `1/2`；[实机数值记录](shishan-code-origin-iteration-runtime-2026-09-29.md)分别给出矿工劳动力 `1042→1051`、机器人能量维护费 `28.7651→28.5012`、住房需求按人数归一后的 `0.99→0.98`、物理学家科研 `7.88→7.95`。兼容采矿特质还有未满岗的[独立数值对照](shishan-code-origin-pr05-compat-runtime-2026-09-28.md)。

**PR-05 按既定验收标准通过。** 19 个兼容候选的数值采用原版定义逐项比较，实际人口模板由原生压力存档验证；没有把 39 种候选逐个另开一局测 GUI 数值，也没有以抽样估算概率。项目正常结算时“只发一次”的证据由 PR-01/02/04 和重复结算专项记录提供，压力夹具不替代这些路径。其他物种/帝国不被发奖由正式效果的唯一 `owner_main_species` 目标静态审计与正常项目样本共同约束。
