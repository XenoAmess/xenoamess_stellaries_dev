## 生成记录与验收标准

每次生成都创建独立尝试目录，保留原始提示词、公开请求参数、任务状态或失败信息、原始生成图；不保存 API 密钥与临时签名下载 URL。保留失败但已产生图像的尝试，不覆盖任何既有结果。`assets/shishan-code-origin/generated/` 是记录根目录，`assets/shishan-code-origin/prompts/` 存放计划版提示词；最终选用文件另建立清单，指向对应尝试，保留来源链。

逐张检查：A01–A11 中透明项确有 alpha 通道，边缘与画面四角为透明、没有白色矩形背景；A02/A05/A12 为不透明图；白绮五个核心特征一致且无文字水印；图标在约 30–40 像素预览下能分辨，维护与清理、故障与重构容易区别；宽幅图保留裁切安全区。记录像素尺寸、透明比例和人工目检结果。透明预览能力若导致不可用图片，保留原尝试并重新生成；仍不可用则明确标记为未通过，不伪称完成。

本任务只验收素材生产与记录，不宣告 Mod 的 P 语言、实机或发布验收完成。
