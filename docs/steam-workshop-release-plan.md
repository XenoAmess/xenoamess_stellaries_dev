## 发布门禁

发布前必须全部满足：

1. 用户已下达发布指令；按本文件冻结的追加 BBCode 和 Change Note 执行。
2. `VERSION`、描述符、机器合同和 `CHANGELOG.md` 已同步推进为 `1.0.1`，Steam Change Note 与该版本 changelog 一致。
3. I1-003 简体中文反向可见性通过：普通帝国与非机仆机械帝国均看不到计划 13。
4. `open_kaishek` 对生产 Mod 的 P 语言入口全部 `VALIDATED`，仓库自动化测试通过。
5. 从干净 Git 提交构造上传目录，重新核对 Mod 树哈希、`descriptor.mod` 版本和文件清单；首次上传包不得携带上游 `remote_file_id="3710613857"`。
6. 在发布界面明确选择创建新物品，并记录 Steam 返回的新 Workshop ID；任何界面若显示将更新 `3710613857`，必须立即取消。
7. 上传完成后核对新物品 ID、标题、说明前缀、追加 BBCode、Change Note、更新时间及重新下载的文件内容，并确认上游 `3710613857` 未变化；随后把新 ID 写回描述符、文档和合同，创建并推送 Git 标签 `v1.0.1`。
