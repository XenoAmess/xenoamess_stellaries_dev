发布前必须全部满足：

1. 用户批准追加 BBCode 和 Change Note。
2. `VERSION`、描述符、机器合同和 `CHANGELOG.md` 已从候选版同步晋升为 `1.0.0`，Steam Change Note 与该版本 changelog 一致。
3. I1-003 简体中文反向可见性通过：普通帝国与非机仆机械帝国均看不到计划 13。
4. `open_kaishek` 对生产 Mod 的 P 语言入口全部 `VALIDATED`，仓库自动化测试通过。
5. 从干净 Git 提交构造上传目录，重新核对 Mod 树哈希、`descriptor.mod` 版本和文件清单。
6. 确认当前 Steam 登录账号拥有物品 `3710613857`，并确认上传目标 ID，而不是创建新物品。
7. 上传完成后核对物品 ID、说明前缀、追加 BBCode、Change Note、更新时间及重新下载的文件内容；随后创建并推送 Git 标签 `v1.0.0`。
