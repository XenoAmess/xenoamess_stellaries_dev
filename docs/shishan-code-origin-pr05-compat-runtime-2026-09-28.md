# PR-05 兼容机械特质实机数值对照（2026-09-28）

## 目标、范围与方法

验证维护奖励的第二层“兼容的非机械正面特质”中，`trait_shishan_compat_industrious` 在 Stellaris 4.5.1 的机械主体物种上确实产生矿工加成。原版“采矿钻头”和该兼容特质都定义为 `miner_jobs_bonus_workforce_mult = 0.15`。本次在只启用本 Mod 的简体中文隔离存档中做三组连续对照；控制同一行星、同一机械主体物种、同一岗位与合法采矿区容量，并保存每组截图和游戏存档。

原始矿工岗位达到或超过容量时，劳动力倍率难以从产出判断。夹具先用原版 `d_metal_boneyard` 合法增加采矿区上限，再建设采矿区，使矿工容量稳定为 `2000`、三组均未满员。特质变更后跨越月度刷新点再读数。此前一天内读数不变的探针不能判定特质无效；岗位劳动力分配在本夹具中需要跨月观察。

## 数值与存档核对

| 暂停日 | 兼容特质 | 原版采矿钻头 | 劳工人数 | 矿工有效劳动力 | 矿物岗位产出 | 矿物产出/矿工劳动力 |
| --- | --- | --- | ---: | ---: | ---: | ---: |
| 2207.08.24 | 1 | 1 | 921 | 1289/2000 | 60.66 | 0.04706 |
| 2207.09.25 | 1 | 0 | 927 | 1158/2000 | 54.50 | 0.04706 |
| 2207.10.25 | 0 | 0 | 933 | 1019/2000 | 47.95 | 0.04706 |

三份 `gamestate` 中兼容/原版特质出现次数依次为 `1/1`、`1/0`、`0/0`，`d_metal_boneyard` 均出现一次。两次移除 `+0.15` 特质后，矿工劳动力依次减少 `131`、`139`；同时劳工总数分别自然增加 `6`，因此差值并非严格等人数控制。矿物产出与矿工有效劳动力成比例，单位劳动力产出在显示精度内一致。劳动力/劳工总数约为 `1.400`、`1.249`、`1.092`；末组存在少量非矿工分配，不能将最后比值视为精确的单人倍率。

结合原版同修正的阳性对照，以及兼容特质移除后第二次劳动力下降，结论是：**该兼容特质在实际游戏中生效**。这只通过 PR-05 的一个机械兼容映射子项；其他奖励候选、四种迭代类别与研究项目自然完成链仍需逐项验收。
