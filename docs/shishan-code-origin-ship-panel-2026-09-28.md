# 五阶段舰船面板实机对照（2026-09-28）

## 目标与范围

在 Stellaris Cygnus 4.5.1、简体中文、Steam 离线且只启用正式「屎山代码」Mod 的个体机械局中，固定一艘护卫舰、舰长、设计、科技及游戏日期，单独切换「大厦将倾」阶段，检查舰船面板的亚光速速度与伤害数值。此项验证游戏已把国家阶段修正作用到真实舰船属性；受控战斗的单次命中与同段实际航行时间仍另测。

## 方法与验收标准

从 `2203.06.03` 暂停存档开始，选择「加拉索舰队」首艘特玛斯级护卫舰「果敢的多纳布」。先记录自然第一阶段面板，再取消舰队选择，在玩家国家作用域通过游戏控制台 `effect every_situation={set_situation_progress=N}` 分别置入第二至第五阶段的 `300/500/750/950`。每次确认右侧局势阶段符号更新，再重选同一舰队和舰船，不推进日期。以第二阶段为对照，I/III/IV/V 的伤害与亚光速速度应分别约为 `1.25/0.75/0.50/0.25` 倍；UI 整数与两位小数允许四舍五入差异。

游戏控制台默认使用当前选中作用域。第一次选中舰队时执行相同命令，仅显示 `Executing effect script`，局势未变；先关闭舰队详情并取消选中，再次从玩家国家作用域执行，控制台明确回显「所有活跃的局势：大厦将倾局势设定为 300.00」，右侧阶段变为 II。后续每次也在取消舰队选择后执行。第一次无效调用不作为阶段测试证据。

以第二阶段伤害 `8.82` 为基线，乘 `1.25/0.75/0.50/0.25` 得 `11.025/6.615/4.41/2.205`，与五个面板两位小数的值相符。速度 `163` 为整数显示，跨阶段呈同一倍率趋势：`204/122/81/40`，与从舰船底层速度先施加阶段修正、再显示整数的结果相符。此项通过舰船属性生效检查；还不能把面板的「伤害」等同于战斗中每一发实际命中伤害，也不能把「速度」面板当作真实航行时间测试。
