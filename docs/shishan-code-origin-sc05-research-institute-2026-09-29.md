# SC-05 研究所岗位转换实机验收（2026-09-29）

## 目标与范围

在 Stellaris Cygnus 4.5.1 简体中文的正式单 Mod 局里，补齐研究所与一座原版研究实验室同星球共存的岗位来源证据。分别使用机械智能与个体机械帝国存档；每一分支都在正常建筑准入后建造原版研究实验室，确认原版社会学岗位保留，研究所自身提供的维护员岗位数量准确，建筑能量维护费及岗位资源维护费仍按原版/Mod 定义结算，保存并从游戏内重载。

## 设计与验收方法

正式研究所的 `building_shishan_code_institute` 对两类政体分别提供 `100` 个 `shishan_code_maintainer_drone` / `shishan_code_maintainer` 劳动力；其建筑能源维护费为 `2`。两个 Mod 岗位社会学基础产出均为 `2`。4.5.1 原版 `calculator_biologist` / `biologist` 的相应基础值应为 `3`，各自维护费须从原版当前脚本读取；比较的是基础定义，实机最终岗位产出会受阶段、国家、行星和人口修正影响。

从已归档、能重载的正式局存档创建独立分支。先确认原版实验室可在同一星球建造，再正常建成或仅为节省等待时间使用原版 `instant_build` 完成已由 GUI 准入的队列，并立即关闭加速。保存建筑前后及游戏内重载后的存档与 Steam F12 截图；抽取 `gamestate` 中同一星球的建筑、原版社会学岗位与维护员岗位的 `workforce/max_workforce/pop_groups`，不得用其他星球或 AI 国家岗位凑数。观察局势月速度与实际已分配维护员劳动力匹配，避免空岗位误算。

## 判定标准

两类帝国同星球均有一座原版实验室和至少一座本研究所；建造研究所不会删除实验室提供的原版社会学岗位，反之亦然。每座研究所只贡献一个等效 `100` 劳动力维护员岗位，无额外原版社会学岗位；两种岗位的基础社会学产出之差为 `1`，消耗与建筑维护费同脚本。存档重载后建筑数、实际岗位劳动力、局势减速不额外变化。正式 Mod 需先经 `C:\workspace\open_kaishek` 验收，通过后才能宣告本项通过。

## 实机结果

个体机械分支在首都已有两座研究所、原版 `biologist=60` 劳动力时，经原版建筑界面准入并建成一座 `building_research_lab_1`。同一首都的原版生物学家增加到 `120/120`，维护员保持 `200/200`；游戏内重载后两项仍为 `120/120` 与 `200/200`，局势月速仍为 `+4.8`。建筑面板同时显示两座研究所和一座原版研究实验室。存档与画面见 `assets/shishan-code-origin/evidence/sc05-individual-*`。

机械智能分支的首都原已并存三座研究所和一座原版研究实验室。拆除一座研究所前，原版 `calculator_biologist=120/120`、维护子个体 `300/300`、局势月速 `+5.7`；同一暂停日拆除后，原版岗位仍为 `120/120`，维护子个体变为 `200/200`，局势月速 `+5.8`。从游戏菜单重载后数值保持。建筑面板和岗位画面见 `assets/shishan-code-origin/evidence/sc05-gestalt-*`。存档的全局建筑对象池可能保留已拆除建筑的旧对象，因此建筑数以当时 GUI 的在用建筑和首都岗位为依据，不以对象池的原始字符串数为依据。

4.5.1 原版脚本的两个生物学岗位基础社会学产出均为 `3`；本 Mod 两种维护岗位均为 `2`，基础差值 `-1`。原版个体生物学家的消费品维护费为 `1.5`，维护员也为 `1.5`；原版机械智能生物学家的能量维护费为 `3`，维护子个体也为 `3`。原版实验室与本研究所的建筑能量维护费均为 `2`。这些是正式脚本的基础定义；界面最终产出、维护费还受当时国策和局势影响，不把不同岗位的最终 UI 数字误当基础定义对照。
