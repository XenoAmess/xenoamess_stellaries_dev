# 创意工坊页面加入 A02 起源插画：v0.1.2

## 目标与范围

用户指定把[现有 A02 原图](https://github.com/XenoAmess/xenoamess_stellaries_dev/blob/main/assets/shishan-code-origin/generated/A02-attempt-01/original.png)加入公开创意工坊的 BBCode，并要求完成后继续 Mod 测试验收。A02 是已经入库的起源插画，提示词及原图随既有美术资源保存；本轮不重新生成或修改画面。现有八张真机截图继续保留在正文和画廊。

## 设计

在起源开篇设定下方插入 A02 原图，使用返回 `image/png` 的 GitHub Raw 直链，不使用会返回 HTML 的 GitHub `blob` 页面地址。为图添加简短的起源插画说明，避免把概念插画误称为真机截图。页面图片清单按 BBCode 实际顺序记录一张插画与八张真机截图的来源、URL、SHA-256 和字节数；八张截图仍作为 Steam 画廊预览，A02 仅嵌入正文。

按仓库版本规则建立尚未发布的 `0.1.2` 正式版：先更新根目录 `VERSION`、描述符、正式 changelog 与以 `[v0.1.2]` 开头的 Change Note，冻结提交并推送后，再更新已拥有的 Workshop 物品 `3810136486`。只读上游物品 `3710613857` 保持不变。若需要新上传工具，复用 v0.1.1 的 Steamworks 流程，同时允许已入库 PNG 插画出现在 BBCode 中，而画廊仍只接受八张截图。

## 验收标准

1. BBCode 原文和图片清单已入库；A02 使用用户指定文件的未改动原图，Raw URL HTTP 200、`image/png`、字节数与本地一致。正文中九张图片 URL 与清单逐项一致。
2. 正式 Mod 的 `open_kaishek PASS`；十种语言键和兼容范围不变。简中 UI 的既有通过项不因页面图片变动而重判；其余九种语言静态校验通过，运行时不在范围内。
3. 先推送发布源，再更新正确物品。远端 BBCode 与本地逐字一致；Steam 客户端或网页实际显示 A02 图，八张真机截图仍能显示。匿名远端包与冻结正式包逐文件一致；上游物品未变。发布后推送 `shishan-code-v0.1.2` 标签。
4. 发布完成后继续 PR-02 引擎中断等余下测试，不把本次页面更新当作整体验收完成。
