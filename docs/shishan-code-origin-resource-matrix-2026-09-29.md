# RS-01—RS-04 来源矩阵复核（2026-09-29）

## 目标、范围与方案

复核已归档的同基线简中实机存档，以玩家国家 `budget.current_month.income` 的来源类别作为单笔收入的隔离观测口径。第一、三、五阶段的三份存档都在 `2207.12.05` 完成同一次月结算；第二阶段的 `2207.11.05` 存档仅作前一个月的基值参照，不能与另外三份混称同日对照。输入存档见[原始来源调查](shishan-code-origin-resource-source-audit-2026-09-28.md)。

自动化检查须逐个提取四份 ZIP 存档首位玩家国家预算的收入来源与资源数值，输出可复查的 JSON。对 I/III/V 三份同时非零的项目，计算 `I−III` 与 `III−V`；两差额应相等，且在可核实基础产出的来源上各等于该基础量的 `50%`。这证明阶段从 `+25%`、`−25%` 到 `−75%` 时来源变化线性；仅凭等差并不能排除两项同值的修正叠加，仍须与脚本中每种资源仅一个阶段生产键、已有岗位基础产出对照结合。对第二阶段因月份不同而变动的岗位数值，不能要求它恰是另三阶段的中点。

RS-03 的资源转移、市场、一次性奖励和维护费采用已有独立受控证据；本矩阵不拿生产预算代替这些排除项。RS-04 的原版加成与混合物种劳动继续单独标记覆盖状态。若输入存档阶段或来源对应关系不符、某项缺失或差额超出存档五位小数精度，保持待测并追查，不能自动判通过。

## 执行记录

使用仓库脚本 [`tools/shishan_code/audit_resource_source_saves.py`](../tools/shishan_code/audit_resource_source_saves.py) 解析玩家国家 `0` 的首个预算，并把完整数值、输入 SHA-256 与逐项判定写入[来源矩阵 JSON](../assets/shishan-code-origin/evidence/resource-source-matrix-2026-09-29.json)。输入四份存档的 SHA-256 分别为：I `2708e5048cf6a4654d0368a52f5f782152a55374772aabd15e1b0172a0c703da`、II `66593691a17fba39f73911c76601fccbb0be685206755da8ca222ca33a162dab`、III `4dff358a880a97a25b90cc9ee75817621b05265880702abf00845c852113e47d`、V `c3eafc6c35cff3046057fb4c82a3dddebe1ba9b4ffd8367d6359255ea7432b65`。矩阵 JSON 的 SHA-256 为 `ce88d62b7450cddba5ce7c30a587c4ae1d2a0416ccb01fb7a5ff795361939b5b`。

结果：**26/26** 个在 I/III/V 三份同日存档中同时存在的“来源×资源”项目，`I−III` 与 `III−V` 相等，精度为预算的五位小数。其中国家基础、力量投射、采集/研究站和星港模块共 **14/14** 项还与上月 II 阶段基值的 `1.25/0.75/0.25` 倍严格相符；这 14 项同前月基值相比来源未发生变化。余下 **12** 项为具体岗位或人口类别贸易值，第二阶段存档日期早一个月，不能把它当成固定劳动力同日对照，但 I/III/V 三支的每项收入均随阶段按相同增量变化。

| 同日来源例子 | I | III | V | 每跨 50 个百分点的差额 |
| --- | ---: | ---: | ---: | ---: |
| 国家基础能源 | 25 | 15 | 5 | 10；II 基值 `20` 的一半 |
| 轨道采集矿物 | 12.5 | 7.5 | 2.5 | 5；II 基值 `10` 的一半 |
| 工程师岗位工程学 | 2.74334 | 1.75334 | 0.76334 | 0.99；同岗位 `66` 有效劳动力乘原版每百劳动力基础 `3` 后所得 `1.98` 的一半 |
| 冶金师岗位合金 | 21.95316 | 14.25316 | 6.55316 | 7.7 |

本 Mod 的四个有效阶段脚本对每种资源各只有一条 `country_*_produces_mult`，未同时定义岗位/空间站产出阶段键；工程师岗位实测差额也与原版基础量的单次阶段变化一致。将预算按类别分开，等价于分别观察各笔纯来源；同一份预算内岗位、国家基础与空间站的合计又是混合来源观测。`100` 岗位加 `40` 非岗位的数字在验收计划里是便于心算的标准化例子；实际输入采用可重载的 `1.98+10+3` 工程学基值，第一/三/五阶段逐笔变化完全符合每项只应用一次阶段百分点。这里没有把不同月份岗位的绝对收入硬凑成 `125/75/25`。

此矩阵为 RS-01 的多资源岗位来源、RS-02 的基础/空间站来源和 RS-03 的同资源混合项补强。完整戴森球、稀有轨道资源、结晶熵固定产出、先进逻辑岗位以及税收/双边合同/市场/一次性奖励等使用各自已有的受控记录，不能从本矩阵外推。RS-04 的不同物种混合劳动力与原版加成组合仍须单独复核；在这些缺项完成前，RS 总项保持“部分通过”。
