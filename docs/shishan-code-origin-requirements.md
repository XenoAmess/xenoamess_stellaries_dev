# 「屎山代码」独立 Mod：需求记录

状态：需求已录入，玩法范围经用户确认；本轮仅设计，不实施 Mod。记录日期：2026-09-26。

## 1. 产品边界

- 新增起源「屎山代码」，开局主体物种必须是机械物种。机械智能格式塔和非格式塔个体机械帝国均可选。该玩法是**独立新 Mod**，不改变现有「无限岗位」Workshop 物品。
- 核心体验：开局暂时强势，但底层代码逐渐崩坏；玩家用维护、专职岗位和最终重构控制风险。起源选择界面要明确标出「具有挑战性的起源」。
- 剧情设定：机械文明原为创造者的服务机器；创造时技术不足，之后长期用补丁覆盖问题；创造者于多年前失踪，文明独自维护底层代码并抵达太空时代。
- 进入游戏后通过简短事件链获得唯一传奇领袖「负疚者·白绮」，英文名 `Vivhite`。她是不会老死的机械智能生命，意外死亡后可花少量资源复活。

## 2. 原始数值与行为合同

| 对象 | 用户提出的合同 |
| --- | --- |
| 主体物种 | 起始带一个「屎山代码」特质；可用物种特质点减少 `6`，可选特质上限增加 `3`。 |
| 开局局势 | 「大厦将倾」，基础进度每月 `+1`；每完成一次「维护屎山」再 `+1` 月度速度；维护员岗位面板每 `100` **已分配劳动力**使月度速度 `-0.1`；最终月度速度不得低于 `0.2`。 |
| 第一阶段 | 岗位效率、舰船武器伤害、非岗位来源的月度资源产出、亚光速航速各 `+25%`；岗位维护费 `-25%`。确认区间 `0–250`。岗位与非岗位两项效果不作用于同一笔收入。 |
| 第二阶段 | 无效果。确认区间 `250–500`。 |
| 第三阶段 | 上述四项各 `-25%`；岗位维护费 `+25%`。区间 `500–750`。 |
| 第四阶段 | 上述四项各 `-50%`；岗位维护费 `+50%`。区间 `750–950`。 |
| 第五阶段 | 上述四项各 `-75%`；岗位维护费 `+75%`。进度 `950` 及以上长期保留，直到清理完成或维护归零。 |
| 「清理屎山」 | 社会学研究成本 `8000 + 2000 × 已完成维护次数`；完成时结束局势，移除主体物种「屎山代码」，添加「重构完成」（岗位效率 `+25%`）。 |
| 「维护屎山」 | 社会学研究成本 `2000 + 1000 × 已完成维护次数`；完成时局势进度归零、之后月度速度增加、清理成本提高，并给主体物种一个随机正面特质。 |
| 「屎山维护研究所」 | 游戏开局解锁；把建筑自身提供的社会学家转换成「屎山维护员」，该岗位社会学研究基础产出比原岗位低 `1`，并通过实际分配的劳动力降低局势速度。每星球不限建筑数量。 |
| 局势结束后 | 同一循环项目显示为「持续优化」；社会学研究成本翻倍；每次完成有 `10%` 概率重新进入「大厦将倾」。 |
| 白绮科研效果 | 她存活且受雇时，初始全局工程学研究速度 `+10%`，每次完成「维护屎山」再 `+5%`；初始全局社会学研究速度 `-5%`，每次再 `-2.5%`，负面效果最多 `-75%`。死亡待复活期间暂时失效。 |
| 白绮对话 | 平时随机自责台词；完成维护时随机感谢与分担台词；完成清理时随机释然台词；持续优化触发局势复发时随机回应。 |

### 用户提供的对白原句

下列原句保留用户标点和措辞；详细设计中的扩写候选可以与原句一起组成随机池。

| 情景 | 原句 |
| --- | --- |
| 日常交谈 | 「这都是我的错」「太迟了……」「我……没能做到」「我……无能为力」「对不起……都怪我」 |
| 完成维护 | 「……谢谢你……」「……这是我的责任……辛苦你了……」「……我感到……温暖……」 |
| 完成清理 | 「……终于……结束了……」「……我……可以休息一下了……」「……感谢你……帮我完成了这件事……」 |
| 优化后复发 | 「……又回到了原点……」「……看来……我还需要努力……」「……这次……我不会再失败了……」 |

## 3. 用户已确认的补充规则（2026-09-26）

- 五阶段前两段改为 `0–250` 和 `250–500`；后三段遵循原文 `500–750`、`750–950`、`950+`。
- 机械智能格式塔与非格式塔个体机械帝国都允许选择；采用独立新 Mod。
- 可用特质点减少 `6`，可选特质上限增加 `3`。
- 第五阶段持续存在，直到玩家清理或维护；白绮仅在存活且受雇期间提供全国效果。
- 最新确认的经济口径：岗位效果只覆盖岗位来源的资源产出；原称「月度资源」的效果只覆盖**非岗位来源的持续资源产出**。两类收入按来源分开，同一笔产出不得同时获得两项阶段效果，也不得将两项加成相加或相乘。非岗位部分包含采集站、巨构建筑、帝国固定产出等持续生产，**不包含附庸上缴、贸易协定或每月市场交易**。资源种类仍以覆盖全部持续产出资源为目标；研究所只转换自身提供的社会学岗位。此条取代此前「所有月收入与岗位效率允许叠加」的口径。
- 「持续优化」成本为 `2 × (2000 + 1000n)`，优化成功后也使累计次数 `n` 增加 `1`。
- 原版非重复正面机械特质池耗尽后，只从**对机械物种确实生效**的原版非机械正面特质中抽取；第二层合格候选也耗尽后，维护与优化才改为可逐次累加的随机小幅正面增益。
- 白绮意外死亡可支付 `500` 能量币与 `200` 合金复活，保留等级、经验和已获特质。
- 持续优化触发局势复发时，移除「重构完成」并恢复「屎山代码」。
- 研究所每颗星球不限建造数量。
- 「屎山维护研究所」游戏开局即解锁；进度减速每 `100` 按岗位面板已分配劳动力计算。
- 白绮**禁止玩家主动解雇**；意外死亡仍按既定费用与成长保留规则复活。
- 独立 Mod 首版提供当前 Stellaris 全部官方语言的本地化。当前安装的 `localisation/languages.yml` 与目录列出 10 种：`l_english`、`l_braz_por`、`l_german`、`l_french`、`l_spanish`、`l_polish`、`l_russian`、`l_simp_chinese`、`l_japanese`、`l_korean`。仅简体中文进入实机回归，其余九种进行静态校验。
