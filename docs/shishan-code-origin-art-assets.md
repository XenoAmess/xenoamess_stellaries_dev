# 「屎山代码」独立 Mod：美术资源清单

状态：**素材需求设计与本机原版调查；尚未制作或验收素材**。日期：2026-09-26。对应[需求记录](shishan-code-origin-requirements.md)、[详细设计](shishan-code-origin-design.md)与[测试验收方案](shishan-code-origin-acceptance-plan.md)。本 Mod 不增加新舰船、物种可选肖像、星球模型或自定义 UI 窗口，因此本清单只覆盖已有界面中的新内容。

## 1. 结论与计数口径

原版图片可以先作为脚本占位，**技术原型不要求先画原创图**。为了让独立起源和白绮拥有完整视觉身份，正式版建议准备 **12 份不同的成品视觉资源**：起源 2、物种特质 2、共享剧情/局势图 1、特殊项目图标 2、建筑 1、岗位 1、白绮肖像 1、白绮专属领袖特质 1、Mod 封面 1。以下尺寸是本机原版文件的**实例或推荐导出规格，不是引擎统一强制尺寸**。图标最好保留高分辨率透明源稿，最终按实际显示尺寸导出并在游戏里检查。

## 2. 交给画师的统一要求

- 交付**高分辨率源稿 + 分层文件（若有） + 无字透明版**；我负责按目标游戏版本导出 DDS、绑定脚本和测试裁切。图标透明，A02/A05 横幅可不透明；白绮尽量提供人物与背景分层。所有图均保持可再编辑，便于后续更换尺寸或修正 UI 裁切。
- 小图标以轮廓优先，不依赖可读的程序代码字符。共享视觉语言：损坏阶段用断裂、红橙故障光；维护与重构用蓝青修复光；白绮以灰白为主，保留少量故障色，避免和普通机械单位图标混淆。
- 游戏内图不烘焙简体中文或英文标题，文字交给本地化；封面可有短标题。每张图需有明确可用于 Mod 与 Workshop 分发的来源与授权记录。若借用原版作为临时占位，尽量**引用游戏已有路径/精灵**，不要把原版 DDS 复制进发布包。
- 同一张 A05 图可绑定多个 `GFX_` 精灵，不代表要复制多份纹理。原型期可先用原版事件图、阶段数字和通用项目图标，待具体界面落地后再决定是否制作补充素材。

## 3. 本机原版证据与验收

调查自本机 `C:\Program Files (x86)\Steam\steamapps\common\Stellaris`（2026-09-26）：`common/governments/civics/00_origins.txt` 中起源同时引用 `icon` DDS 路径与 `picture` 精灵；`interface/origin_eventpictures.gfx` 绑定起源插画；`common/situations/03_origin_situations.txt` 和 `99_README_SITUATIONS.txt` 含局势 `picture`、阶段/结果/处理方向图标；`common/special_projects/00_projects_origins.txt` 的项目同时有 `picture` 与 `icon`；`common/buildings/05_research_buildings.txt`、`common/pop_jobs/02_specialist_jobs.txt`、`common/traits/05_species_traits_robotic.txt`、`000_documentation_leader_traits.txt` 提供建筑/岗位/特质图标参考。尺寸由这些实际 DDS 的 Pillow 读取结果取得；不是跨版本接口保证。`gfx/portraits/portraits/19_portraits_paragon_legendary.txt` 与 `21_portraits_cybernetics_synthqueen.txt` 显示领袖纹理还需肖像配置/实体，因此 A10 的最终纹理布局须先做实机探针。

本仓库现有 Mod 描述符使用 `picture="thumbnail.png"`。Steamworks 的 [Workshop 实施指南](https://partner.steamgames.com/doc/features/workshop/implementation)与 [ISteamUGC 接口文档](https://partner.steamgames.com/doc/api/isteamugc)说明 Workshop 可以设置主预览图，常用 JPG/PNG/GIF；额外预览文件另有小于 `1 MB` 的限制。A12 的尺寸是本项目建议，不能把额外预览文件限制误写成主预览图通用限制。

素材验收时检查：所有被引用文件与 `GFX_` 键存在且不冲突；DDS 能加载、透明边缘不发白、横幅不同缩放下主体不被裁掉；40/29/30 像素图标仍可区分；白绮在领袖列表、详情和交谈窗口均显示同一形象；两类机械帝国的建筑/岗位图标正确；启动器与工坊封面不丢图。游戏、UI、OCR 和存档回归仅使用简体中文；其他语言只做本地化静态校验。本清单是**制作计划**，没有实际生成图片或进行实机验收。
