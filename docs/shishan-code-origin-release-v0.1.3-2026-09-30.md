# 屎山代码 v0.1.3 正式修复版发布方案（2026-09-30）

## 目标与范围

在公开 v0.1.2 的后续简中实机验收中发现：原版 `abort_special_project` 中断研究中的「维护屎山」会永久删除项目，现有 `on_cancel` 没有在该路径触发。文档先行修复已在本地 `0.1.3-rc.1` 候选版通过原生存档十项审计，并回归了已重构分支。本轮将同一脚本修复作为新正式 `0.1.3` 发布到项目拥有的创意工坊物品 `3810136486`。原上游 `3710613857` 只读。A02 起源插画和八张真机截图继续留在详细 BBCode 中。

## 发布设计与闸门

1. 依据[资源来源收口](shishan-code-origin-rs-closure-2026-09-30.md)、[奖励池收口](shishan-code-origin-pr05-reward-closure-2026-09-30.md)、PR-01—04 各专项和其余已通过矩阵，先更新总验收记录。候选脚本不再修改；将唯一版本源 `VERSION` 与 `descriptor.mod` 从 `0.1.3-rc.1` 同步改为 `0.1.3`，把候选 changelog 提升为正式条目，写明新增、变更、修复、兼容范围、验收与限制。正式 Change Note 以 `[v0.1.3]` 开头并与同版 changelog 一致。
2. BBCode 页尾版本改为 v0.1.3，并准确说明简中单 Mod 矩阵已按当前 4.5.1 收口；A02 原图与八张游戏截图顺序、URL、哈希及画廊保持。复制 v0.1.2 图片清单为 `page-images-v0.1.3.json` 并仅更新版本字段；新上传脚本以同样的每图 SHA-256、A02 和八图数量验证，绝不把插画当作实机截图。新验证脚本检查公开说明逐字相等、预览与图片、匿名下载的全部 Mod 文件、Change Note、原上游未变。
3. 正式包先运行 `open_kaishek`；简中候选实机原生存档 10/10 审计、奖励池 8/8、资源来源六项复核及翻译静态检查全部应通过。九种非简中语言只写“静态校验通过，运行时不在范围内”。预发布版不得上传。先提交并推送正式源和验收证据，再短时切 Steam 在线上传；若提交失败或安全预检未通过不得上传。
4. 成功上传后查询公开 API、Steam 客户端页面和 Change Note，匿名 SteamCMD 下载验证 64 个文件与正式源逐字节一致，确认 A02 在正文可见、八张真机截图仍在；远端更新及收据入库后再推送 `shishan-code-v0.1.3` 标签。随后切回 Steam 离线。若上传失败且远端无更新，可沿用 `0.1.3` 重试；一旦远端成功不得复用版本号。
