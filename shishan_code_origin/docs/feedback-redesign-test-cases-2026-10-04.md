## 5. Reroll 精确时序

冷却 cd 和每票据 used 标记是不同状态。cd=0 不代表同一票据可以连续使用；使用后本轮确认的选择算第一次。

| ID | 前置与操作 | 预期与重点证据 |
| --- | --- | --- |
| RR-01 首次使用 | 冷却 0、池有至少 4 项、待选票据未 used；点击重抽一次，再尝试点击。 | 第一次免费重抽且 cd=3、used=true，n/R/项目研究次数不增，实际资源不扣；第二次同票据禁用。 |
| RR-02 三次确认 | 第 1 次票据使用重抽后确认；再完成两次真实项目并确认，第 4 次进入待选。 | 第 1/2/3 次成功确认后 cd 为 2/1/0，第 4 次可重抽。每次只能递减一次；其它事件不加选择计数。 |
| RR-03 未使用和失败操作 | cd=0 时正常选、不用重抽；cd>0 时关闭/重开、点击失败按钮、跨月、取消/中断研究。 | 没使用则 cd 保持 0；后述操作不能减少 cd、产生票据或额外候选。合法实体选择才按 cd>0 减一次。 |
| RR-04 自动奖励不计选择 | cd=2 时耗尽两层，连续两个项目自动补丁；另构造单一候选且须最终确认。 | 自动补丁后 cd 仍为 2；单一实体候选确认则 cd=1。没有替代项时无法重抽，不影响确认作为一次选择。 |
