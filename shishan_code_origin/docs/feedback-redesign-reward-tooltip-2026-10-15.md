# 奖励选项内部效果提示隐藏

日期：2026-10-15。先记录设计，再修改生成器与产物。此分工只开发/程序检查，不启动游戏或操作屏幕；最终 rc.3 的包级工具与简体中文 UI 复验由主任务统一执行。

## 证据与目标

主任务 rc.2 实机截图 `_runtime/shishan_code/20261015-runtime/runs/20261015T071829Z/reward1-visible.jpg` 显示：奖励选项虽有自定义特质说明与人口覆盖提示，原生自动效果 tooltip 仍展开模板克隆、变量清零、人口计数/迁移等大量内部操作，遮住事件窗口并泄漏脚本变量名。已只读查看现有截图，未进行截屏或桌面操作。主任务另观察到第一次 console effect 的提示计算有临时变量未设置警告；不能仅凭隐藏 tooltip 就宣称全部警告已修复。

本机已有 `script_documentation/effects.log:10-16` 明确：`hidden_effect` 阻止其中效果出现在 tooltip，支持所有 scope；`custom_tooltip` 显示指定本地化字符串。因此保留选项顶层的自定义提示与允许条件，把真实执行部分放入 `hidden_effect`，使玩家看到特质效果/国内覆盖与 reroll 可用条件。

## 范围与设计

- 仅修改 `tools/shishan_code/generate_rewards.py` 及生成的 `mod/events/shishan_code_rewards_events.txt`；保留主任务已完成的候选、窗口锁、冷却、结算与事件链逻辑。
- 39 个领取选项的领取调用包在 `hidden_effect`，`custom_tooltip`、`trigger`、AI 权重保持顶层。reroll 的内部状态机调用和“稍后选择”的窗口锁释放亦隐藏；reroll 的 `allow`/自定义失败说明保持顶层。
- 无执行体的“关闭”按钮不添加空隐藏层。事件 immediate 保持原行为，既有本地化、奖励效果/触发器、版本与 changelog 不属于本分工。
- 仅重写生成器返回的事件产物，不运行会重写全部共享文件的生成器 main。用程序比较确认生成器事件产物一致，另两个生成脚本文本保持不变。

## 验收

独立程序检查公开 option 表面只能含名称、可用条件、自定义说明、AI 权重及隐藏执行区；39 个候选的自定义说明仍存在于公开区，reroll 的失败说明仍可见。新增负例确保把执行体移出隐藏区或把自定义说明误藏进去会失败。执行真实 AST 的领取/reroll/later 选项，确认隐藏容器仍执行结算、三次选择冷却和窗口锁逻辑，而不是只检查字符串形状。

本轮需要通过无 GUI 单元检查、既有奖励状态回归和事件 P 语法解析；不得把静态通过写成 UI 已修复。最终自然悬停不显示内部变量/clone/迁移文本、提示不遮挡窗口、临时变量评估日志及完整领取/reroll/later 交互，留给主任务 rc.3 简体中文实机复验。

生成器其他两份产物在改前改后逐字节输出摘要一致：effects SHA-256 `93589b9d972b937859a7296859587a15381b9a57514424c50db51194d5834607`，triggers SHA-256 `2f26a1bdc9fc3420411a0ebcb12c4424a0c7c593568a0b85a5241b255cbe0e71`。主任务后续随机修复可能再改变这些产物；这两个摘要仅证明本次 option 包装没有改变它们。
