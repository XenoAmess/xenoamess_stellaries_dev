# 吞噬之心

独立 Stellaris Mod 的设计阶段目录。目标是让灭绝帝国吞噬真实星球、增加母星人口与可建区划容量，通过正常岗位、合法飞升和武力天灾经营战争供养的单球经济。

Mod 正式名称已由用户确认为「吞噬之心」，定位偏强爽玩。普通星球吞噬周期为 3～5 年，20 格默认 4 年；主验收配置启用用户已拥有的 Nemesis 与「虚境之影」。目前只建立文档，尚无可加载 Mod、版本号或 Workshop 物品；其余初始数值仍是候选。
