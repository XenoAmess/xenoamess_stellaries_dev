# 吞噬之心

独立 Stellaris Mod。灭绝帝国吞噬真实星球、增加母星人口与可建区划容量，通过正常岗位、合法飞升和武力天灾经营战争供养的单球经济。

定位偏强爽玩，普通星球吞噬周期为 3～5 年，20 格默认 48 个有效推进月。当前版本以 [VERSION](VERSION) 为准，包位于 `mod/`，适配本机 Stellaris `4.5.2`。当前候选已通过脚本／资源／十语言包级检查，尚未公开发布；简中实机验收继续，不能把静态结果当作玩法已通过。

首发安排为全部政体入口保持开放，焦土蜂巢完成其适用验收后先发布，只推荐焦土蜂巢；其它路线尚未完成整条实机验收，发布后继续测试与修复。验收范围与延期项见[首发合同](docs/scorched-hive-first-release-2026-10-08.md)。这项安排不表示焦土蜂巢目前已完整通过。
