# 吞噬之心

独立 Stellaris Mod。灭绝帝国吞噬真实星球、增加母星人口与可建区划容量，通过正常岗位、合法飞升和武力天灾经营战争供养的单球经济。

定位偏强爽玩，普通星球吞噬周期为 3～5 年，20 格默认 48 个有效推进月。当前版本 `0.2.0-rc.1`，包位于 `mod/`，适配本机 Stellaris `4.5.2`。已通过脚本／资源／十语言包级检查；中文实机、存档及自然经营仍在验收中，尚未公开发布，不能把静态结果当作玩法已通过。
