# 吞噬之心

当前开发候选为 `0.4.0-rc.3`，正式目标为 `0.4.0`，尚未发布。新开局只保留对应母星，取消额外赠品星球；旧档现有星球保持。母舰配置、无限成长、巨像吞星与最终候选的验收进度见[1019任务记录](docs/requirements-2026-10-19.md)。公开版本仍为 `0.3.1`，已完成[1015专项及发布核验](docs/publication-0.3.0-2026-10-15.md)。噬岩者完整验收保持[停止](docs/terravore-acceptance-stopped-2026-10-15.md)，本次开局回归不计为完整政体验收。

本候选新开局需要 Nemesis，直接获得「化身天灾」，仍保留种族飞升准入。母星获得额外一条并行民用建造队列，以及一艘按遗迹级无畏舰配置加强、带10船坞的母舰（新配置待实机验证）；母舰占100海军容量。蜂巢、机械智能和其它合格灭绝帝国分别获得蜂巢、机械或遗落母星，新开局不再额外赠送世界、人口或设施。旧存档不追补开局资产与危机，也不会自动删除已有赠品星球。

母舰吞星共生按累计有效物质 C 计算：每10单位升一级，等级 `L=floor(C/10)`，无等级上限。每级额外伤害、舰体、装甲、护盾各+5%，舰体与装甲固定日恢复各+0.1；实际面板增幅受其它帝国修正影响。候选已加入护盾、装甲、舰体、火力、索敌、再生六类真实硬件核心，每5级等概率永久升级其中一类；大量历史欠额分批补发。组件实际增益、随机发放、重载和旧档迁移仍待本轮实机验收。

候选「饕餮解构光束」设计为通过原生充能发射，直接拆解自有非核心或交战敌国的天然殖民星，无需陆军，收益与成长归母星。目标必须有正的有效物质；任何帝国母星核心、人工天体、殖民中、地面战斗中、正在吞噬或已结算的星球均排除。取消发射不发奖励。实际发射、共同结算、取消与重载防重仍待最终候选简中实测。

在母星的原生「决议」中觐见女王；在自有合格目标上迁移母星。全帝国自动吞噬默认关闭，可通过决议切换，当前母星始终受保护。在活动源星可查看战记或取消拆解；取消保留此前已经发生的收益和人口移动，并暂时豁免该星球的自动吞噬，直至手动恢复。关闭全帝国开关只停止启动新任务，已有任务需另行取消。王庭岗位产出在无危机时为10%，随武灾1～5级变为20%～60%。

独立 Stellaris Mod。灭绝帝国吞噬真实星球、增加母星人口与可建区划容量，通过正常岗位、合法飞升和武力天灾经营战争供养的单球经济。

定位偏强爽玩，普通星球吞噬周期为 3～5 年，20 格默认 48 个有效推进月。当前版本以 [VERSION](VERSION) 为准，包位于 `mod/`，适配 Stellaris `4.5.2`。[创意工坊物品](https://steamcommunity.com/sharedfiles/filedetails/?id=3815707212)的0.3.1完整47文件、远端正文、Change Note、封面及六张图库已核验。

历史完整实机验收仅0.2.0焦土蜂巢（现正式简中名“纵火本能”），首发推荐该路线；其它路线开放但未完成完整实机验收。首发31项适用合同及最终生产冒烟通过，噬岩专项2项不适用，详情见[首发验收结果](docs/first-release-acceptance-result-2026-10-08.md)。0.3.1通过[1015约定专项](docs/acceptance-1015-result-2026-10-15.md)，不新增完整政体验收结论。0.4.0的中间原型已通过open_kaishek包级静态检查，生产内容仍在变化，最终冻结包须重新检查并完成[1019验收](docs/acceptance-1019-plan.md)。十语言文本的键、编码、引用、保护token和占位修正见[本地化状态](docs/localization-1019-status.md)；其它九语言运行时不在范围内。原生决议科研库存行为及覆盖兼容限制见[CHANGELOG](CHANGELOG.md)。
