# 吞噬之心

当前本地为 `0.3.0-rc.1`，1015需求已实现并完成约定范围的专项验收，尚未上传创意工坊；已公开版本仍为 `0.2.0`。[本批验收结果](docs/acceptance-1015-result-2026-10-15.md)逐项列出证据、严格差分失败及有界例外。女王入口迁入决议体系、移除星球GUI覆盖；新增自动吞噬开关（默认关闭）及新开局队列、母舰和同类殖民地。噬岩者完整验收保持[停止](docs/terravore-acceptance-stopped-2026-10-15.md)，不将本批专项计为完整政体验收。

本候选新开局需要 Nemesis，直接获得「化身天灾」，仍保留种族飞升准入。母星获得额外一条并行民用建造队列，以及一艘约两倍同国原版灰风军力、带10船坞的母舰；母舰占100海军容量。蜂巢、机械智能和其它合格灭绝帝国分别获得蜂巢、机械或遗落母星，以及同类20格、100本族人口的额外殖民地。上述开局资产与危机不向旧存档追补。

在母星的原生「决议」中觐见女王；在自有合格目标上迁移母星。全帝国自动吞噬默认关闭，可通过决议切换，当前母星始终受保护。在活动源星可查看战记或取消拆解；取消保留此前已经发生的收益和人口移动，并暂时豁免该星球的自动吞噬，直至手动恢复。关闭全帝国开关只停止启动新任务，已有任务需另行取消。王庭岗位产出在无危机时为10%，随武灾1～5级变为20%～60%。

独立 Stellaris Mod。灭绝帝国吞噬真实星球、增加母星人口与可建区划容量，通过正常岗位、合法飞升和武力天灾经营战争供养的单球经济。

定位偏强爽玩，普通星球吞噬周期为 3～5 年，20 格默认 48 个有效推进月。当前版本以 [VERSION](VERSION) 为准，包位于 `mod/`，适配 Stellaris `4.5.2`。[0.2.0 已发布至创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3815707212)，独立下载全部41文件及远端正文、Change Note、封面与六张图库已核验。

已公开`0.2.0`的完整实机验收仅焦土蜂巢，首发推荐焦土蜂巢；其它路线开放但未完成完整实机验收。首发31项适用合同及最终生产冒烟通过，噬岩专项2项不适用，详情见[首发验收结果](docs/first-release-acceptance-result-2026-10-08.md)。本次`0.3.0-rc.1`只通过[1015约定专项](docs/acceptance-1015-result-2026-10-15.md)，不新增完整政体验收结论。其它九语言静态校验通过，运行时不在范围内；原生决议科研库存行为及覆盖兼容限制见[CHANGELOG](CHANGELOG.md)。
