# 吞噬之心

正式 `0.4.0` 已于2026-10-20发布至[Steam创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3815707212)，远端59文件、公开正文、更新记录及全部图片已核验，`v0.4.0`标签已推送。新开局只保留对应母星，取消额外赠品星球；旧档现有星球保持。母舰配置、无限成长和巨像吞星已完成[1019约定专项验收](docs/evidence/1019-requirements/final-result.json)，范围与限制见[发布记录](docs/release-0.4.0-execution-1020.md)。噬岩者完整自然战役仍保持[停止](docs/terravore-acceptance-stopped-2026-10-15.md)，专项通过不等于完整政体验收。

新开局需要 Nemesis，直接获得「化身天灾」，仍保留种族飞升准入。母星获得额外一条并行民用建造队列，以及一艘按遗迹级无畏舰配置加强、带10船坞的母舰；母舰占100海军容量。蜂巢、机械智能和其它合格灭绝帝国分别获得蜂巢、机械或遗落母星，新开局不再额外赠送世界、人口或设施。旧存档不追补开局资产与危机，也不会自动删除已有赠品星球。

母舰吞星共生按累计有效物质 C 计算：每10单位升一级，等级 `L=floor(C/10)`，无等级上限。每级额外伤害、舰体、装甲、护盾各+5%，舰体与装甲固定日恢复各+0.1；实际面板增幅受其它帝国修正影响。护盾、装甲、舰体、火力、索敌、再生六类真实硬件核心每5级等概率永久升级其中一类；大量历史欠额分批补发。实际增益、随机发放、跨进程重载和两条固定旧档迁移已通过限定专项。

「饕餮解构光束」通过原生充能发射，直接拆解自有非核心或交战敌国的天然殖民星，无需陆军，收益与成长归母星。目标必须有正的有效物质；任何帝国母星核心、人工天体、殖民中、地面战斗中、正在吞噬或已结算的星球均排除。取消发射不发奖励。实际发射、共同结算、取消、保护条件与重载防重已完成简中专项实测。

在母星的原生「决议」中觐见女王；在自有合格目标上迁移母星。全帝国自动吞噬默认关闭，可通过决议切换，当前母星始终受保护。在活动源星可查看战记或取消拆解；取消保留此前已经发生的收益和人口移动，并暂时豁免该星球的自动吞噬，直至手动恢复。关闭全帝国开关只停止启动新任务，已有任务需另行取消。王庭岗位产出在无危机时为10%，随武灾1～5级变为20%～60%。

独立 Stellaris Mod。灭绝帝国吞噬真实星球、增加母星人口与可建区划容量，通过正常岗位、合法飞升和武力天灾经营战争供养的单球经济。

定位偏强爽玩，普通星球吞噬周期为 3～5 年，20 格默认 48 个有效推进月。当前版本以 [VERSION](VERSION) 为准，包位于 `mod/`，适配 Stellaris `4.5.2`。0.4.0的独立下载59文件、远端正文、Change Note、封面、六张图库和四张内嵌图片均已核验。

历史完整实机验收仅0.2.0焦土蜂巢（现正式简中名“纵火本能”），首发推荐该路线；其它路线开放但未完成完整实机验收，详情见[首发验收结果](docs/first-release-acceptance-result-2026-10-08.md)。0.3.1通过[1015约定专项](docs/acceptance-1015-result-2026-10-15.md)。0.4.0最终冻结包通过open_kaishek：36/36 P脚本、12 DDS、132本地化键×10语言，18组合同为PASS_SCOPED；实机仅简体中文，其它九语言静态校验通过、运行时不在范围内。旧伤迁移的原严格FAIL与固定v2微小误差预算、单人postload布局校正、多人未实测等限制保留于[CHANGELOG](CHANGELOG.md)。
