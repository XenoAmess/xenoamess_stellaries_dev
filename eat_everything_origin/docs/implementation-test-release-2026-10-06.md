# 吞噬之心：首版实施、测试与发布计划

日期：2026-10-06。工作基线：`7cea3e52267b47624909dfdbc81ce086249afcff`。用户已明确授权依次实现、测试、发布，并要求完成前持续推进。状态：实施中；验收与发布尚未完成。

## 目标与范围

按[主设计案](../../docs/eat-everything-origin-design-2026-10-06.md)、[女王玩法职责](queen-baiqi-gameplay-design-2026-10-06.md)及[验收方案](acceptance-plan.md)交付独立起源：灭绝资格、母星绑定、噬岩与通用吞星、真实容量和本族人口、女王事件与王庭报告、灵飞／武灾节点、存档恢复、十种官方语言及图像。候选数值采用现有方案，普通 20 格吞星 48 个有效推进月。

首轮以当前半身 V2、正面立绘 V5 作为实施基准；这是用户实现和发布授权下的选用，不冒称逐项美术审核已明确通过。独立透明图片继续使用 EvoLink；事件 CG、起源插画与封面保留参考、逐字提示词、请求、任务和原图，再转换为游戏资源。

新代码仅位于本子项目；使用 `eep` 命名空间，唯一版本源为子项目根 `VERSION`，包放 `mod/`。先使用 `0.2.0-rc.1`，验收通过后形成正式 `0.2.0` 与正式 changelog，再创建新的 Steam Workshop 物品。兼容范围先限定本机实际验收的 `4.5.2`，禁止修改只读上游物品 `3710613857`。

3. 实现国家与母星持久状态、源星任务与成功凭证。先实现正常流程，再覆盖肃清等待、母星失守、源星易主、中断重启、并行结算和重载；展示事件不发第二份经济奖励。

5. 整理美术与十语言文本；非中文只进行静态验收，实际游戏、UI、OCR、存档和经济回归仅使用简体中文。

## 测试与证据

- 先执行 open_kaishek 包级验收，冻结游戏版本、EXE、工具提交、脚本与资源指纹；包级 PASS 只代表语法和包结构。
- 实机在独立 userdir 中只加载本 Mod 与明确标识的测试夹具，不覆盖玩家存档、播放集和设定。夹具可使用原版效果构造边界条件，但正式包不含测试决议、无条件奖励或绕过资格入口。
- 按 PROBE-01～09、EAT-01～33 记录实际结果。正常局势推进、源星毁灭、真实人口变化、岗位/区划可建设性、重载和 UI 必须保留原生存档、日志、截图／OCR；直接调用完成事件只能算受控回调检查。
- 独立离线检查用于凭证、引用、键、编码、版本、资源与公式合同，不能取代实机语义。若某项未执行、失败或被环境阻塞，记录实际状态并继续解决，不以缩小报告口径冒充完成。
- 自然经营记录首战、首轮吞星、母星建设与长期停战；维护成本、规模与原版收入分别统计。记录性能和多任务成本，正式代码不得每日扫描全银河。

用户已经明确授权发布，不再重复询问。优先复用仓库已有 Steamworks 发布与远端核验实现，在新物品创建成功后记录新 ID；验证远端描述、版本、Change Note 与下载文件哈希，再创建并推送标签 `v0.2.0`。本仓库的 `v0.1.0` 已由其它 Mod 使用，因此首版选用尚未占用的 `0.2.0`，发布标签为 `v0.2.0`，不覆盖其它项目标签。

## 实施记录

- 开发阶段原生存档、日志与 OCR 证据以原始字节的 SHA-256 关联；该目录使用局部 `.gitattributes` 禁用 Git 行尾转换，避免提交后日志 CRLF 被改为 LF 使既有证据指纹失效。仅证据目录适用，不改变脚本和本地化的编码要求。
- 普通局势重载后在下个月调用完成，但阻塞结算时引擎记录 incorrectly ended 并结束局势，不能保留末期等待。最终候选恢复 permanent=yes，每次 on_monthly 的真实 Situation 事件安排次日终点核验；用 situation_progress>=冻结 T 置 pending 并受保护结算。次日使检查明确发生在当月引擎推进之后，终点不额外多等一个月；每任务每月一次延期事件，不每日扫描国家或银河。上下文拥有权比较使用 target 的 prev.owner，避免元脚本继承的 root 栈。当前两种失败方案均留档，最终候选尚待复验。
- 结算中先保存局部绑定母星与原发起国，人口回迁与随后制造／威慑记账显式使用这些对象；迁走源星最后人口不应丢失收款国引用。只对开发存档新增加的报告字段填 0，不重新绑定或重发开局收益。
