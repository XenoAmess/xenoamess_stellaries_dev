## 目标与范围

按[主设计案](../../docs/eat-everything-origin-design-2026-10-06.md)、[女王玩法职责](queen-baiqi-gameplay-design-2026-10-06.md)及[验收方案](acceptance-plan.md)交付独立起源：灭绝资格、母星绑定、噬岩与通用吞星、真实容量和本族人口、女王事件与王庭报告、灵飞／武灾节点、存档恢复、十种官方语言及图像。候选数值采用现有方案，普通 20 格吞星 48 个有效推进月。

首轮以当前半身 V2、正面立绘 V5 作为实施基准；这是用户实现和发布授权下的选用，不冒称逐项美术审核已明确通过。独立透明图片继续使用 EvoLink；事件 CG、起源插画与封面保留参考、逐字提示词、请求、任务和原图，再转换为游戏资源。

新代码仅位于本子项目；使用 `eep` 命名空间，唯一版本源为子项目根 `VERSION`，包放 `mod/`。先使用 `0.2.0-rc.1`，验收通过后形成正式 `0.2.0` 与正式 changelog，再创建新的 Steam Workshop 物品。兼容范围先限定本机实际验收的 `4.5.2`，禁止修改只读上游物品 `3710613857`。

用户已经明确授权发布，不再重复询问。优先复用仓库已有 Steamworks 发布与远端核验实现，在新物品创建成功后记录新 ID；验证远端描述、版本、Change Note 与下载文件哈希，再创建并推送标签 `v0.2.0`。本仓库的 `v0.1.0` 已由其它 Mod 使用，因此首版选用尚未占用的 `0.2.0`，发布标签为 `v0.2.0`，不覆盖其它项目标签。

最终交付包含正式 Mod、测试报告、工坊链接、远端内容核验、提交与标签。无关工作树改动不纳入提交。当前尚无任何新 Mod 验收或发布 PASS。
