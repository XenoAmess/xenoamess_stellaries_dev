## 不增加矩阵的最终组装方式

1. 先收各线程不可变归档／proposal、实际report和角色receipt，保留同名原件与失败边界。当前RC7活动run的最终完整日志在停止后统一冻结一次，供适用组共用；不拿早期阶段日志冒充整run日志。
2. 当前源稳定后，用既有scaffold-index建新的RC7 PENDING副本；reference plan只提供已存在静态报告／archive引用。未有canonical run manifest时runs留空，不能填未来路径。
3. 归档到位后，现`runtime_index_1019.py`添加唯一RC7 run／证据／原始budget观测；helper仍不接受整组。将各线程typed提案显式合并并逐check审查，不复制RC6 source tree、旧case PASS或原错误政策。
4. 所有18组与组件完成、迁移精确RC7 producer身份适配完成，才另建final-result；status、IMPLEMENTED及各check由共同审查决定，不用自动promote。
