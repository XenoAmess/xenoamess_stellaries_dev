# 母舰加强计划（1019需求追加前的历史方案）

后续授权：用户已提出 [1019 实施需求](requirements-2026-10-19.md)，明确按遗迹级配置加强、设计成长并加入巨像拆解。下文的旧配置、“尚未授权”、“尚未实施”和阶段成长都是追加需求前的调查快照，不是当前实现状态；最新范围与验收进度以 1019 文档为准。成长已改为每10物质升一级、四项各+5%、无限级，每5级随机组件正在验证，旧阶段方案不实施。

## 目标、授权与范围

用户追加反馈“母舰好垃圾。它不是有跃迁引擎吗，推进器也不是满级”，本轮要求梳理加强方案并提供计划清单。此文件只记录调查和拟议方案；尚未授权具体参数实施。正在进行的0.3.2单母星开局、母星配置修复与发布继续，母舰改动需独立候选、回归和版本，不沿用本轮经济结果宣称加强后通过。

目标是让唯一母舰成为可随主力行动、有真正主动跃迁、能持续远征造舰的旗舰；加强效果对蜂巢、机械、普通合格政体一致，旧存档现有母舰也应有明确升级路径。保留十个移动船坞和独立唯一目标，不通过发放全帝国科技实现。

## 已核实的现状

- 当前`mod/common/global_ship_designs/eep_mothership.txt`实际配置是`HYPER_DRIVE_1`（超空间引擎I），不是`JUMP_DRIVE_1`。推进器为`SHIP_THRUSTER_3`（等离子推进器），传感器为`SENSOR_2`，反应堆为`TITAN_COLD_FUSION_REACTOR`，电脑为`COMBAT_COMPUTER_ARTILLERY_ADVANCED`。
- 创建时舰队`can_upgrade=no`、舰船`upgradable=no`，因此也不能期待玩家后续科技自动补齐其装备。设计锁定本身可保留，但必须给出足够好的固定组件或专用成长规则。
- 底盘实际为原生`juggernaut`，拥有十船坞，低基础速度、加速度0.2、转向0.15。已有独立修正`ship_speed_mult=0.8`，但高修正不等于正确的基础组件和快速转向。
- 原版`07_scripted_triggers_ships.txt`规定主宰使用巨像级推进器（`ship_uses_colossus_thrusters`）和主宰级反应堆。当前使用的小船推进器／泰坦反应堆与底盘原生组件类别不一致；这是源码调查结论，尚未实测该不匹配具体导致哪些运行差异。
- 原版`PSI_JUMP_DRIVE_1`可增加50%跃迁范围，预热修正-80%；`JUMP_DRIVE_1`为-70%。原生跃迁基础预热14日、范围100、冷却200日；冷却期静态修正为伤害-50%／速度-50%。实际母舰UI、舰队上下文和叠加后参数仍须实测。
- 原版`COLOSSUS_SHIP_THRUSTER_5`为暗物质推进器，基础速度修正+125%；`JUGGERNAUT_DARK_MATTER_REACTOR`具有原生物流光环，也有组件能量／合金维护，不能仅根据“装满级”就宣称完全免维护。
- 历史专项将军力校准到同国灰风约两倍；没有完成覆盖不同敌方编成的战斗胜率基准。当前实机母舰实际计100海军容量，即使舰队保存`uses_naval_capacity=no`。纸面军力、实际战斗、航行和经济负担需分别验收。

本次调查使用本机4.5.2原版源码（精确EXE SHA见0.3.2任务记录）：`18_juggernauts.txt`、`00_utilities_drives.txt`、`00_utilities_thrusters.txt`、`00_utilities_reactors.txt`、`07_scripted_triggers_ships.txt`、`06_static_modifiers_apocalypse.txt`、`00_defines.txt`及正式简中本地化。以上属于Stellaris具体实现，不推广到CK3。

## 推荐实施清单

| 顺序 | 改动 | 推荐目标与验收 |
| --- | --- | --- |
| P0 | 真正的跃迁能力 | 直接为唯一母舰装备灵能跃迁引擎，三个政体均可使用，不授予国家科技；实机按钮可用、可选目标、实际完成跳跃并在存档核位置。 |
| P0 | 满级且匹配底盘的动力 | 换用巨像级暗物质推进器、主宰级暗物质反应堆、快子传感器；核总供电、实际组件、UI与航行速度，禁止仅换图标／名字。 |
| P0 | 跟队机动 | 以同国同日满级战列舰为对照，测同一路线出发到达、预热和转向；调整母舰专属速度，使其能随主力远征。加速度／转向是否需专用舰型，先做接口验证。 |
| P1 | 跃迁后的可用性 | 建议冷却目标100日，母舰专属免除冷却期伤害／速度惩罚；验证原生专用旗标和冷却接口后再定实现，不能修改全局常量或让其它舰队获得豁免。 |
| P1 | 移动基地实用性 | 保留十船坞；重新验证边走边造、停靠修理、受损友舰返航与补舰集结。需要额外维修能力时只影响母舰服务范围。 |
| P1 | 母舰的经济负担 | 目标是本体实际能量／合金维护为0，海军容量降到合理旗舰级（建议20，上限待原生接口核验）；必须从国家预算和存档验证，不把已有无效flag写成达成。造舰材料仍正常支付。 |
| P2 | 实战火力与生存 | 先在同国灰风及固定护卫舰群／战列舰群／星基三类对手上比较损失、战斗时长、射程与存活；按短板调整武器、电脑、点防或恢复，不直接把未测军力倍数当战斗保证。 |
| P2 | 成长 | 根据危机／女王阶段提升母舰专属火力或耐久，开局已有完整机动；每阶段触发一次且可重载，不重复叠加。具体幅度由P2战斗对照后确定。 |
| 必做 | 旧存档升级 | 研究原生现有舰设计更新接口；保留唯一母舰身份、位置、舰名、生命比例和建造队列，不复制母舰、不返还重复资源。迁移不可可靠保留时先报告限制，不能默认要求重开。 |

优先交付P0与旧档迁移；P1涉及经济及原生舰型行为，需复测三类开局12个月，不能复用0.3.2旧经济结果。P2在机动和后勤实用性成立之后实施，另有量化战斗基准。
