# Machine经济补充归档 v2

v1的344个源文件及其索引保持原字节。v2补足两次原生保存名称编辑的底层Ctrl+A记录；底层执行器按`press-时间戳.json`命名，原fm前缀白名单没有收录它们。它们分别在`fmm00reload-name`、`fmyearui-name`之前两秒内，只有Ctrl+A，没有额外文本或提交。

`supplement-v2/` 保存实际UI执行器源、原版物流岗位／game_start源、旧版母舰优惠源、复现采集器和新的限定报告。每源双读SHA和复制后SHA均应相同。`archive-index-v2.json`引用v1索引和全部旧文件，不改变历史receipt或任何已归档资料，也不复制活动日志、Hive或PK分支。

六项声明只在报告各自scope内通过。四经济操作约束依据实际111条输入、22次截图／OCR绑定点击、九资源逐月预算闭合、14个原生检查点的岗位限制及全部初始舰船身份；人口与维护另以同preset原生旧基线、冻结源码及非零实际成本核对。它们不证明任意未记录外部输入不存在，也不把正常物流trade收益当补贴。整体发布仍PENDING。
